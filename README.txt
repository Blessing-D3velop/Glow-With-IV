# Glow With IV – Beauty & Wellness Website

🌐 **Live Website:** https://www.glowwithiv.co.za/

**Client Project | Designed & Developed by Blessing Muthivhi**

## About the Project

Glow With IV is a beauty and wellness website I developed to help the business showcase its treatments, products and services through a professional online platform.

The main goal was to create a clean, modern and visually appealing website where potential clients can explore available treatments, learn more about the business, view its gallery and easily get in touch.

I focused on creating a smooth browsing experience while making sure the website works properly across different screen sizes.

## Features

- **Modern Homepage:** A professional landing page introducing the business and its services.
- **Services Showcase:** Dedicated sections highlighting available beauty and wellness treatments.
- **Image Gallery:** A collection of business images with interactive viewing functionality.
- **Gallery Lightbox:** Visitors can open images in a larger view.
- **Responsive Navigation:** Mobile-friendly navigation with a collapsible menu.
- **Contact & Booking:** Easy access to business contact information and appointment enquiries.
- **Interactive Elements:** Smooth scrolling, animations and interactive buttons.
- **SEO Optimisation:** Search engine metadata, structured page information and indexing support.
- **Developer Credit:** A dedicated developer credit in the website footer.

## Search Engine Optimisation (SEO)

SEO was an important part of this project. I implemented several improvements to help search engines understand the website and its content.

These include:

- SEO-friendly page titles and meta descriptions.
- Relevant keywords throughout website content.
- Open Graph metadata for social media sharing.
- Image alt attributes for accessibility and search context.
- XML sitemap.
- Robots.txt configuration.
- Search engine indexing support.
- Website performance and accessibility improvements.
- Custom domain and deployment configuration.
